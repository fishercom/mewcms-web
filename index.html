MewCMS

Elegance, built in.

A content system for teams who run many sites, in many languages, with quiet confidence.

Try the live demo View on GitHub

Every site you run, every language you speak, every page you publish. One calm place to shape them all.

Open source · Laravel · Inertia · React · AGPL v3

Chapter I

Many sites, one home.

Run each brand, campaign or region as its own site, with its own domain, languages and theme, all from one admin.

  • Switch sites without losing your place
  • Themes live in their own repositories
  • Themes can bring their own blocks or stay light-only
Chapter II

Compose with blocks.

Build pages from ready-made blocks and see them drawn in the site's own theme while you edit.

  • Hero, columns, gallery, slider, stats, quote, video, form and more
  • Save any arrangement as a reusable pattern
  • Live preview with the theme's stylesheets
Chapter III

An editor that writes with you.

Ask for an outline, a first draft or a better paragraph. You stay the author; the assistant does the heavy lifting.

  • Suggested titles, descriptions and keywords
  • Outline and draft a page from a short brief
  • Works with Claude or any OpenAI-compatible provider
Chapter IV

Every language, natively.

Each site chooses its languages. Pages, menus and interface text follow, with help from the assistant when you need a first translation.

  • Languages per site, menus per language
  • Translation dictionaries you can edit
  • Assisted translation of whole pages
Chapter V

A calm admin.

A sidebar that folds away and keeps your section open, one clear confirmation before anything is lost, and a dashboard that shows what changed.

  • Revisions, trash and scheduled publishing
  • A warning before leaving unsaved work
  • Activity and content at a glance
Chapter VI

Secure, fast, findable.

Role-based permissions and an activity log keep the team safe. A page cache, sitemaps and redirects keep visitors and search engines happy.

  • Permissions per role and module
  • Sitemap, redirects and an SEO review per page
  • Cached public pages that refresh when you publish

And everything a site needs, already there.

Slides with images, video and buttons, managed per page.

Familiar code, no plugin maze.

MewCMS is a Laravel application with an Inertia and React admin. A theme is a folder you can read, test and version, and a theme block is a JSON file plus a React component.

Read the code 
// blocks/testimonial.json
{
  "name": "Testimonial",
  "icon": "quote",
  "fields": [
    { "key": "quote", "type": "textarea" },
    { "key": "author", "type": "text" }
  ]
}
// front/blocks/testimonial.tsx
import { type BlockRenderProps } from '@/blocks/types';

export default function Testimonial({ data }: BlockRenderProps) {
  return (
    <blockquote>
      {data.quote}
      <cite>{data.author}</cite>
    </blockquote>
  );
}
