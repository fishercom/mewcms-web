MewCMS features

An open-source CMS with everything built in.

One install runs every site you have, in every language you need. Here is what comes with it, before you add a single plugin.

Multi-site

Many sites, one install.

Each site is matched by its domain and keeps its own pages, posts, menus, forms, sliders, redirects and layout settings. Slugs only have to be unique inside their site, so two brands can both have an “About” page.

Media, tags, post types and languages are shared, so a team works from one library. A switcher in the admin header picks the site you are working on, and every list follows it.

  • One build and one admin for every domain
  • A theme, colours, font, title and favicon per site
  • Head and body scripts per site, for analytics and the like
Themes and blocks

Pages built from blocks, drawn by the theme.

Editors compose pages from ready-made blocks: hero, rich text, columns, gallery, slider, stats, quote, video, form, call to action and more. The editor previews every block with the site’s own stylesheets.

A theme carries a site’s whole design and can add blocks of its own. It only needs the pages it changes; everything else falls back to the default theme.

  • Save any arrangement as a reusable, synced block
  • Templates can limit which blocks a page may use
  • Themes can live in their own repositories
AI assistant

An AI writing assistant inside the editor.

Give it a short brief and it outlines the page, drafts it in the blocks the theme allows, or rewrites a paragraph you have already written. Nothing is published until you say so.

It also suggests the title, description and keywords for search engines, and gives a first translation when a page moves to another language.

  • Works with Claude or any OpenAI-compatible provider
  • Drafts in real blocks, not a wall of text
  • SEO titles, descriptions and keywords on request
Multi-language

A multilingual CMS, natively.

Every site has a main language and may add more. Each extra language answers under its own prefix, such as /en/about, with its own pages, posts and menus, linked to each other from the editor.

The CMS writes the lang attribute, the hreflang links and the sitemap for every language, and a language switcher only appears where there is somewhere to switch to.

  • Languages per site, one menu per language
  • Theme texts editable from the admin, per site
  • Prices, dates and plurals formatted per language
The admin

A calm admin for the whole team.

A dashboard shows what changed and what needs attention. The sidebar folds down to icons and keeps your section open, and nothing is deleted or left behind without one clear confirmation.

Every page keeps its revisions, deleted content waits in the trash, and posts can be scheduled to publish on their own.

  • Revisions, trash and scheduled publishing
  • A warning before leaving unsaved work
  • Light and dark modes
Security, speed and SEO

Secure, fast and easy to find.

Permissions are set per role and per module, page HTML is sanitized on save, public forms are rate limited, and every change and login lands in the activity log.

Public pages are cached and refresh when you publish. Each site gets its own XML sitemap, robots.txt, Open Graph tags and redirects, and every page has an SEO review before it goes out.

  • Roles with view and manage rights per module
  • Sitemaps, redirects and an SEO checklist per page
  • Cached public pages that refresh on publish

Content tools, all included.

Custom fields

Add text, image, repeater, price and other fields to any template, with no migrations.

Post types

Blog posts, products, projects or anything else, each with its own fields.

Taxonomies

Nested categories and tags with clean archive URLs.

Forms

Contact forms with validation, email notices and the submissions in the admin.

Sliders

Slides with images, video and buttons, also used as cards inside blocks.

Media

Folders, drag-and-drop uploads and quick insert into the editor.

Menus

Drag to reorder and nest items, one menu per language.

Search

Site search across pages, posts and the text inside blocks.
